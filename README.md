# Dainty House

Website for **Dainty House**, a private holiday home in Ovar, Portugal.

A single-page static site (HTML, CSS and JavaScript, no build step) in English and Portuguese, with a photo gallery, guest reviews, amenities and location.

Reservations are made on the [Airbnb](https://www.airbnb.pt/rooms/888126764161156334) and [Booking.com](https://www.booking.com/hotel/pt/dainty-house-ovar.pt-pt.html) listings.

Photos, ratings and reviews come from those listings and belong to their respective owners and guests.
